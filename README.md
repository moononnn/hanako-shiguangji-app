# 拾光记 📖

> 给 Hana 里的每一天，留一页可以回看的光。

当前版本：`0.0.48`

当前版本最近一次自动测试结果（2026-10-10）：全量 `node --test` 515/515 通过（33 个测试文件），81 个 JavaScript 文件语法检查通过。（v0.0.47 时为 542 条，差额来自随检查更新死代码一起删掉的 26 条已下线用例。）

## ⚠️ 先说清楚

拾光记会把一些生活信息带进 Hana 的对话，所以有几件事先讲明白：

- 打开「情境注入」后，拾光记会把日期、时间、天气、节日、你记下的日子和近期生活记录整理成背景，让伙伴在合适的时候知道此刻发生在什么日子里。
- 打开「每日做册」后，拾光记会读取 Hana 里符合范围的可见对话，按日期和伙伴整理成一页；这个功能默认关闭。
- 天气功能需要联网，且需要选择具体的居住地；天气开关可以单独关闭。
- 待办到了设定时间，会由拾光记在对话里轻轻提一句。挂不上的时候退回系统通知，不影响你原来的用法。
- 自动整理连续三次没做成会暂停当天，并借「提个醒」的弹窗告诉你一声。没装提个醒、或是刚好撞上它的静默时段，就安静收场，不影响做册本身。
- 你自己记下的日子、待办、生理期和时光册都会加密保存在本机。拾光记不会修改伙伴的身份或性格文件。

## 这是干什么的？

有时候，一天里和伙伴聊了很多事，做了很多小小的决定。等过几天再回头，却只剩下一句「那天好像挺忙的」。

我做拾光记，是想让这些事情有地方落下来，也让 Hana 里的日子有一点连续感。

它一头连着日历，一头连着对话：你可以在页面里记下一天发生了什么，伙伴也会在恰当的时候感知到今天的时间、窗外的天气和你正在惦记的事情。一天结束以后，还能把这一天收成一页时光册，慢慢翻回去看。

## 它能做什么

- 🚪 **左侧门厅一屏看完今天**

  在 Hana 侧边栏点「拾光记」打开的就是门厅：今天的日期、星期和节日做一张深色压舱的今日卡，窗外天气单独成一条，下面是日历 / 时光册 / 心情线 / 生理期四个快捷入口。今天还欠的待办列在门口，**点一下就标完成**，主页面跟着刷新；关掉了生理期，入口也会跟着消失。

  周期待办漏做的那几次，门厅会按任务归拢成欠账，可以逐次勾，也可以批量确认昨天以前确实做完的次数。

  ![](https://raw.githubusercontent.com/moononnn/hanako-shiguangji-app/main/attachments/shiguangji-home.png)

- 🗓️ **记下每天的事**
  
  随手记一笔、补记纪念日、安排待办，也可以记录生理期。一次性的日子、每年重复的纪念日和每天／每周重复的待办分开管理；周期待办每次独立记录完成状态，漏掉几次也不会卡住后续日期。门厅会按任务归拢欠账，可逐次勾选，也可批量确认昨天以前确实做完的次数。新增「生理期规律」后，记录达到一定数量时还能看到历史周期、持续天数、下次预计区间和当前第几天。

  ![日期详情：记录日子、待办和提醒时间](https://raw.githubusercontent.com/moononnn/hanako-shiguangji-app/main/attachments/shiguangji-calendar-detail.png)


- ⏰ **让时间在场**
  
  伙伴能知道当前日期、星期和生活日的边界。情境注入有「适时」「相伴」「常在」三档，跨天或内容发生变化时会及时更新，平时不会把同一段背景每轮重复念一遍。

- 🌤️ **让窗外也在场**
  
  选择居住地后，可以带入天气、温度和昼夜状态。晴天时可能是望一眼窗外，降温时可能是顺手确认要不要添衣，天气会尽量像生活里的一个小动作，而不是一条硬邦邦的播报。

- 🎐 **记住节日和节气**
  
  内置常见节日、法定节假日、农历日子和节气。到了特别的日子，伙伴可以顺着当下的气氛自然聊两句，但不会每次都把节日当标题念出来，也不会替你预设应该怎么过节。

- 🔔 **让待办在该出现的时候出现**
  
  待办支持准点和时间段提醒，标题里写下明确时刻时可以自动填入时间。到了时候，拾光记会把待办带回对话；逾期事项会收敛成轻提示，不让旧账每天刷屏。每天或每周重复的待办会按日历继续提醒，不等上一次勾选才往下走。

  ![自然提醒：拾光记把待办带回对话](https://raw.githubusercontent.com/moononnn/hanako-shiguangji-app/main/attachments/shiguangji-reminder-chat.png)


- 📖 **把一天收进时光册**
  
  一天结束后，可以按伙伴分别整理成一页；支持预看、编辑、重新整理、删除，也可以一次选几天批量做册。每日做册默认关闭，想什么时候开始由你决定。

  自动整理没做成也不会闷着：页面上有一条状态说明，「正在等重试」「连续三次停摆了」「伙伴际遇线还没补完」都看得见，也可以随时点「现在就手动做」自己来一次；失败的任务可以选择取消重做，旧的页面和失败记录都会留着。

  ![时光册：按日期收好一天的记录](https://raw.githubusercontent.com/moononnn/hanako-shiguangji-app/main/attachments/shiguangji-timebook.png)


- 💗 **记一笔当下的心情**
  
  今日卡上可以随手标记当天的心情，原因可留白，一天里不同的情绪变化都会按时段自然收好，不打断聊天。

- 📈 **心情线**
  
  把一天或一段日子的心情变化画成一条柔和的手绘曲线：你亲笔记下的心情是饱和的实心点，伙伴发现的候选用浅一号的颜色轻轻落在旁边，一眼就能分清。曲线随心情高低从薄荷渐变到粉，只看画面也能感到那一整天是明亮还是低沉。只记变化，不给心情打分。
  
  可以看单日，也可以看连续 7 / 14 / 30 天——哪几天稳稳当当、哪几天起起伏伏，铺开一看就有感觉。没记录的日子不硬补点，曲线轻轻跨过去，不给空白日子硬安情绪。
  
  你的心情线旁边还能并排看伙伴的际遇线：按那天伙伴被夸、被凶、被需要这些际遇画出来，颜色按伙伴固定，线的末端标着名字，图例点一下就能收起某一位，只想看一个人时清爽很多。

- 🧩 **遇到问题可以直接反馈**
  
  设置里有「反馈」入口。反馈时可以跟伙伴聊清楚问题，再打开已经整理好的 GitHub Issue 页面，检查无误后由你自己提交。

## 一个很普通的使用场景

你在日历里写下：

> 下午三点带狗狗出去走走。

拾光记会把时间识别成待办提醒。到了时候，它把这件事带回对话，伙伴再用自己的语气提醒你，而不是突然丢一条像闹钟一样的系统口令。

如果这一天和伙伴聊了不少东西，晚上或第二天还可以把它整理成一页，留下当天真正发生过的事。

## 怎么开始

1. 在 Hana 里打开「拾光记」（站点导航或扩展页都能进）。
2. 按需要打开「情境注入」；不想让背景进入对话时，可以随时关掉，也可以只让某几位伙伴不带。
3. 在日历里点选日期，记下一笔日子、纪念日或待办。
4. 想让天气进入对话，就在设置里选择居住地并打开天气。
5. 想使用时光册，再打开「每日做册」，选择做册范围和模型来源。

做册用的模型可以跟随当前伙伴，也可以从 Hana 已配置的模型里选择，或者填写自定义 API。不想额外设置时，保持默认选项就可以。

## 隐私与数据

- 用户自己添加的日子、待办、生理期、设置和时光册使用加密文件保存在本机。
- 内置节日与节气属于公开数据，不包含你的个人内容。
- 每日做册默认关闭；开启后，默认只整理符合范围的可见对话，并避开应用内部会话和隐藏提示。
- 近期生活记录默认按伙伴隔开，不会把一位伙伴的私密回顾随意带给另一位；是否共享由设置决定。
- 天气只有在天气开关打开且已选择地点时才会查询和注入。
- 数据目录位于 `<HANA_HOME>\app-data\shiguangji-app\`（默认的 `HANA_HOME` 是 `%USERPROFILE%\.hanako`；改过数据目录的话，就在你自己设的那个位置）。

## 安装

拾光记是 Hana v2 应用，安装方式和插件不一样，放的是 `apps` 目录：

1. 下载最新 Release 的应用压缩包。
2. 解压后，把 `shiguangji-app` 整个文件夹放进：

   ```text
   <HANA_HOME>\apps\shiguangji-app\
   ```

   默认的 `HANA_HOME` 是 `%USERPROFILE%\.hanako`；如果你在 Hana 里改过数据目录，就换成那个位置。不知道在哪的话，去 Hana 的设置或关于页面看「数据目录」。

   文件夹名要保持 `shiguangji-app`，跟 `manifest.json` 里的 `id` 一致。解压别多套一层，最后要能看见 `apps\shiguangji-app\manifest.json` 这个文件。
3. 重启 Hana，或者去扩展页「已安装」里点「重新加载」。
4. 它要是出现在「待批准」里，先批准；再去「设置 → 安全 → 应用能力」里把它的权限打开。

## 从插件版换过来

以前用插件版拾光记记下的日子、待办、时光册和心情，可以搬到这一版来。

如果这一版在你机器上发现了插件版留下的数据，「设置」最下面会出现「从插件版搬数据」这一块，点一下就把插件版的数据搬过来，搬完页面自动刷新一次。**没有插件版数据的时候，这一块不会出现**（读不到插件目录时会露面一次，把原因说给你听）。

搬的规矩：

- **只读旧的，不删不改。** 插件版那边的文件原样留着，搬动的是副本。
- **不覆盖，按文件整份跳过。** 应用版里已经有的文件一个都不动；粒度是整份文件，不做逐条合并。所以补搬之后可能是「这边原有的某一类 + 从插件版补来的另一类」凑在一起，不是两边逐条混成一锅。
- **只搬一本账。** 日子、纪念日、待办与提醒状态、时光册、心情与伙伴心情线、天气缓存、设置和情境注入状态都会跟着过来。
- **重来也不怕。** 搬过一次之后再点，已经搬过来的那些不会重复，缺的会补上。只搬成一部分的话，会明确告诉你还有几项没搬成，再点一次可以接着补。

搬之前记得两件事：

- **别让两版同时开着。** 先去扩展页把插件版停用（或卸载），搬完核对过记录再决定旧插件怎么处理。两版同时启用会重复注入、重复提醒，也可能两边各记一份账。
- **搬完核对一下。** 日子、待办、时光册、心情是不是都在，对不上就再点一次补搬，或者对照插件版的原文件确认。

要是提示「读不到插件版的数据目录」，去「设置 → 安全 → 应用能力」里确认拾光记的读取权限已经打开，再试一次。实在搬不过去也不要紧，插件版里的记录一直都在，不会因为装了应用版而消失。

搬与否完全由你决定：拾光记不会自己搬东西，也不会把插件版的数据删掉或改掉。

## 卸载

在 Hana 的扩展页「已安装」里卸载，或者直接删掉 `<HANA_HOME>/apps/shiguangji-app`。

卸载应用不会自动删除已经保存的日子和时光册。如果想连数据一起清除，请先关闭 Hana，再删除：

```text
<HANA_HOME>\app-data\shiguangji-app\
```

## 兼容性

## 开发

在源码仓库目录运行全量自动测试（含 `lib/` 里的测试；**安装包里不含测试文件，要跑测试请用仓库**）：

```powershell
node --test
```

检查全部 JavaScript 文件：

```powershell
Get-ChildItem -Recurse -Filter *.js | ForEach-Object { node --check $_.FullName }
```

宿主静态校验用 Hana 自带的 `scripts/validate-app.mjs`，必须读取非空结构化结果，不能只看退出码。测试细节见 [TESTING.md](https://github.com/moononnn/hanako-shiguangji-app/blob/main/TESTING.md)。
